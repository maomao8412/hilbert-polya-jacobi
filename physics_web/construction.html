§2 Reproducible Construction

From completed \(L\)-functions to Jacobi Hamiltonians — every step deterministic, no zeros, primes, or random numbers

Overview: The Four-Step Pipeline

Completed \(L\)-function \(\Lambda(s)\) → Step 1: Contour sampling → Step 2: Moments \(P_m\) → Step 3: Gram–Schmidt → Step 4: Jacobi matrix \(J_N = \mathrm{tridiag}(\alpha_n, b_n)\)

Step 1: Completed \(L\)-functions

We use three completed functions \(\Lambda(s) = \Lambda(c - s)\), each entire and real on the symmetry line:

\(\displaystyle \zeta: \quad \xi(s) = \tfrac{1}{2}s(s-1)\pi^{-s/2}\Gamma(s/2)\,\zeta(s), \quad c = 1\)
\(\displaystyle \beta: \quad \Lambda_\beta(s) = \big(\tfrac{\pi}{4}\big)^{-(s+1)/2}\Gamma\!\big(\tfrac{s+1}{2}\big)\,4^{-s}\big[\zeta(s,\tfrac{1}{4})-\zeta(s,\tfrac{3}{4})\big], \quad c = 1\)
\(\displaystyle \Delta: \quad \Lambda_\Delta(s) = (2\pi)^{-s}\Gamma(s)\,L(\Delta,s), \quad c = 12\)

The Dirichlet beta function encodes the Gaussian integers; \(\Delta\) is a weight-12 modular form. Using three independent arithmetic objects tests universality. We also study the product \(\xi_K(s) = \xi(s)\Lambda_\beta(s)\) as a superposition control.

Step 2: Contour Sampling & Moments

Each \(\Lambda\) is sampled on a circle of radius \(R\) centered on the symmetry point \(s_0 = c/2\):

\(\displaystyle s_k = s_0 + R\,e^{i\theta_k}, \quad \theta_k = \frac{2\pi k}{M}, \quad k=0,\dots,M-1\)

using high-precision arithmetic (mpmath). The mean \(\sigma_0 = \frac{1}{M}\sum_k \Lambda(s_k)\) normalizes the measure. The Taylor coefficients \(d_n\) of \(\log(\Lambda/\Lambda(s_0))\) on the circle are obtained from the discrete Fourier (trapezoidal) sums, and the Hausdorff moments \(P_m\) follow from the logarithmic derivative recurrence:

\(\displaystyle c_n = d_n - \frac{1}{n}\sum_{i=1}^{n-1} i\,c_i\,d_{n-i}, \qquad P_m = (-1)^{m+1}\,m\,c_m\)

Step 3: Gram–Schmidt → Jacobi Coefficients

Monic orthogonal polynomials for the moment functional \(\langle x^i, x^j\rangle = T(i+j) = P_{i+j+1}\) are built by Gram–Schmidt:

\(\displaystyle \alpha_{k-1} = \frac{\langle x\,p_{k-1}, p_{k-1}\rangle}{\langle p_{k-1}, p_{k-1}\rangle}, \qquad b_{k-1}^2 = \frac{\langle p_k, p_k\rangle}{\langle p_{k-1}, p_{k-1}\rangle}\)

This yields the tridiagonal Jacobi matrix \(J_N = \mathrm{tridiag}(\alpha_n, b_n)\) with \(b_n > 0\). Positivity of all \(b_n^2\) through the computed order is verified explicitly.

The Tight-Binding Hamiltonian

The Jacobi matrix is interpreted as a one-dimensional tight-binding Hamiltonian:

\(\displaystyle H = \sum_{n=0}^{N-1}\alpha_n\,|n\rangle\langle n| + \sum_{n=0}^{N-2} b_n\bigl(|n\rangle\langle n\!+\!1| + |n\!+\!1\rangle\langle n|\bigr)\)
Hamiltonian matrix structure (ζ J50, first 20×20 block)

The matrix is tridiagonal: diagonal entries \(\alpha_n\) (blue), off-diagonal hoppings \(b_n\) (orange). All other entries are zero.

Locked-Subspace Protocol

A truncated \(N\times N\) Jacobi matrix reproduces only the lowest zeros. We lock a computed eigenvalue \(\gamma = 1/\sqrt{\lambda}\) when it agrees, to relative error \(< 10^{-4}\), with a zero computed by an independent method. Zeros enter only this after-the-fact check — never the construction.

Construction Algorithm (Pseudocode)

CONSTRUCT-JACOBI(Lambda, c, R, M, dps, N, JMAX):
    set arithmetic precision dps
    for k = 0 .. M-1:                      # Cauchy-circle sampling
        s_k = c/2 + R * exp(2*pi*i*k/M)
        f_k = Lambda(s_k)
    sigma0 = (1/M) sum_k f_k               # normalizes the measure
    for n = 1 .. JMAX:                     # Taylor (Fourier/trapezoid) coeffs
        d_n = Re[ (1/M) sum_k f_k exp(-2*pi*i*(2n)*k/M) / R^(2n) ] / sigma0
    c[1] = d[1]                            # log-derivative recurrence
    for n = 2 .. JMAX:
        c[n] = d[n] - (1/n) sum_{i=1}^{n-1} i*c[i]*d[n-i]
    P[m] = (-1)^(m+1) * m * c[m]          # Hausdorff moments
    T(i,j) = P[i+j+1]                      # moment functional
    p[0] = 1 ;  norm[0] = <p0,p0>          # monic Gram-Schmidt
    for k = 1 .. N:
        x p[k-1]  ->  alpha[k-1] = <x p[k-1],p[k-1]>/<p[k-1],p[k-1]>
        orthogonalize against p[k-1] (alpha) and p[k-2] (b^2)
        b[k-2]^2  = norm[k-1]/norm[k-2]
        norm[k]   = <p[k],p[k]>
    assemble tridiagonal J_N = diag(alpha) + diag(b,+1) + diag(b,-1)
    verify  b_n^2 > 0  for all n           # positive-definiteness check
    lambda = descending eigenvalues of J_N ;  gamma = 1/sqrt(lambda)
    LOCK gamma if |gamma - gamma_zero|/gamma_zero < 1e-4
