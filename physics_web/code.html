Quick Start: Load a Hamiltonian

# loader_demo.py — Load any Hamiltonian and print diagnostics
import numpy as np
import json

def load_hamiltonian(directory):
    """Load Hamiltonian matrix and metadata from a directory."""
    H = np.loadtxt(f'{directory}/hamiltonian.csv', delimiter=',')
    with open(f'{directory}/metadata.json') as f:
        meta = json.load(f)
    return H, meta

def spectral_diagnostics(H, meta):
    """Compute and print basic spectral statistics."""
    evals = np.sort(np.linalg.eigvalsh(H))[::-1]  # descending
    pos = evals[evals > 0]
    gammas = 1.0 / np.sqrt(pos)
    
    print(f"System: {meta['name']}")
    print(f"Matrix size: {H.shape[0]}")
    print(f"Positive eigenvalues: {len(pos)}")
    print(f"First 5 γ (1/√λ): {gammas[:5]}")
    
    # Level spacings
    spacings = np.diff(np.sort(pos))
    spacings /= np.mean(spacings)  # unfold
    print(f"Min unfolded spacing: {np.min(spacings):.4f}")
    
    # Gap ratio
    r = np.minimum(spacings[:-1], spacings[1:]) / np.maximum(spacings[:-1], spacings[1:])
    print(f"⟨r⟩ = {np.mean(r):.4f}")
    print(f"  (GUE: 0.600, GOE: 0.536, Poisson: 0.386)")

# Load ζ J50
H, meta = load_hamiltonian('benchmark_v1/quantum_arithmetic_v1/zeta_J50')
spectral_diagnostics(H, meta)

Reproduction Guide

Prerequisites

Python 3.9+
mpmath >= 1.3          # High-precision arithmetic
numpy >= 1.24           # Linear algebra
scipy >= 1.10           # Special functions (Hurwitz zeta)
matplotlib >= 3.7       # Plotting

Step-by-step reproduction

# 1. Clone the repository
git clone https://github.com/maomao8412/hilbert-polya-jacobi.git
cd hilbert-polya-jacobi

# 2. Run a construction pipeline (example: ζ J50)
python construction_scripts/zeta_J50.py
# Output: coefficient tables, hamiltonian.csv, metadata.json
# Runtime: ~5 minutes on a modern CPU (230-digit arithmetic)

# 3. Run experiment 1 (level spacings)
python physics_experiments/exp1_level_spacings.py
# Output: spacing distributions, gap ratios, Figure 1

# 4. Run experiment 2 (dynamics)
python physics_experiments/exp2_wavepacket.py
# Output: form factor, survival probability, transport, Figure 2

# 5. Run OTOC computation
python otoc_20260831/otoc_experiment.py
# Output: C(t) for all systems, Figure 5

# 6. Verify data matches released files
python benchmark_v1/quantum_arithmetic_v1/loader_demo.py

Dependencies & Runtime

High-precision arithmetic is the bottleneck. The construction uses mpmath at 230–1300 decimal digits. Runtime scales roughly as:

  • \(\zeta\) J50 (230 dps): ~5 min
  • \(\zeta\) J100 (1300 dps): ~45 min
  • Product J100 (650 dps): ~30 min
  • \(\Delta\) J22 (230 dps): ~3 min

The experiment scripts (spectral statistics, OTOC) run in seconds using standard double-precision linear algebra on the pre-computed Hamiltonians.
