Dataset Overview

Hamiltonians

Arithmetic Jacobi Matrices

Four real-symmetric tridiagonal matrices. Each entry derived by a deterministic pipeline from \(L\)-function arithmetic Dirichlet coefficients. No zeros, primes, or spectral information enters the construction.

Each directory contains:
hamiltonian.csv — dense N×N tridiagonal matrix
metadata.json — family, pipeline parameters, statistics

OTOC

Out-of-Time-Order Correlators

Time-domain squared commutator \(C(t)\) for all six systems (4 arithmetic + GOE + uniform), at 5 inverse temperatures \(\beta = 0.5, 1, 2, 5, 10\). 801 time points, \(t \in [0, 40]\).

E₄ Control

Eisenstein Discriminator

Moment sequence, Jacobi coefficients, and sign-change analysis for the weight-4 Eisenstein series \(E_4\), whose zeros lie off the symmetry line.

File Format: hamiltonian.csv

Dense N×N tridiagonal matrix. Row \(i\), column \(j\):

  • H[i][i] = \(\alpha_i\) (on-site energy)
  • H[i][i+1] = H[i+1][i] = \(b_i\) (hopping amplitude)
  • All other entries = 0

Eigenvalues satisfy \(\lambda_k \approx 1/\gamma_k^2\), where \(\gamma_k\) are the corresponding \(L\)-function zero heights on the critical line.

Scope & Limitations (please read)

  • All results are finite-truncation numerical evidence. Nothing here proves any statement about infinite-dimensional operators.
  • The spectra are computer-generated, not measured; this is a simulation benchmark. Physical-simulation experiments are proposed but not yet performed.
  • "Quantum chaos of arithmetic origin" is a physical hypothesis supported by the data, not an established fact.
  • \(\Delta\) reaches only 15 locked levels at 230-digit precision (Hankel conditioning floor); its statistics carry explicit small-sample caveats.
  • Gap-ratio estimates from 15–53 levels have a known upward small-sample bias (Atas et al. 2013); the dataset does not claim GUE vs GOE discrimination.
