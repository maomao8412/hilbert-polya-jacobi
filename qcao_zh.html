摘要

通往量子混沌谱的两条已知途径——经典混沌系统的量子化，以及安德森（Anderson）无序——有一个共同特征：随机性要么通过经典动力学进入，要么通过哈密顿量参数进入。本文报告第三条途径：一维紧束缚哈密顿量，其矩阵元是由完备化 \(L\) 函数确定性地导出的 Jacobi 递推系数，自由参数为零。由 Riemann \(\xi\) 函数构造的 \(50\times50\) 哈密顿量，仅凭 230 位高精度矩量所固定的矩阵元，便以约 \(10^{-15}\) 的相对误差复现前 25 个 Riemann 零点。这些矩阵呈现量子混沌的全套指纹：Wigner 能级排斥、谱形状因子的斜坡（ramp）、波包回复的缺失，以及扩展的本征态。一个保留系数分布但破坏算术递推的"洗牌"对照，会使谱坍缩为泊松（Poisson）统计——这把混沌的起源锁定在递推的结构而非随机性上。该现象在约 \(10\%\) 的乘性噪声下依然存活。我们把这些观察表述为一个物理假设，并为量子模拟器提供一套开箱即用的实验方案。

一、引言：为什么这是一个量子系统？

从一个古老的问题开始。1910 年代，希尔伯特和波利亚各自独立地提出：是否存在一个自伴算子，其本征值恰好是黎曼 ζ 函数非平凡零点的虚部 γn？如果这样的算子存在，黎曼猜想将由谱定理自动推出。一个世纪过去了，无人给出显式构造。

我们的出发点不同。我们不是"寻找"一个算子来拟合零点，而是问一个更根本的问题：L 函数的算术数据本身，能否生成一个量子哈密顿量？

答案是：能。而且这个哈密顿量展现出纯粹的量子混沌行为——尽管它没有经典混沌对应，也没有任何随机性。

核心洞察：量子混沌不一定需要经典混沌作为源头。数论深处的算术结构——素数之间的关联、L 函数的零点分布——本身就能在量子系统中激发出混沌行为。这是一种全新的量子混沌起源。

为什么叫"算术起源的量子混沌"？在传统的量子混沌研究中（如核物理、量子台球、量子点），混沌来自于经典动力学的量子化——一个经典混沌系统的量子版本自然继承混沌特性。我们的系统不同：它没有经典混沌极限，混沌完全来自算术结构本身。

与经典算术量子混沌的"镜像"关系。经典的算术量子混沌理论（Sarnak, 1995）研究算术双曲曲面的量子化。在那里，算术对称性实际上抑制混沌——完整谱趋向泊松统计，只有在固定 Hecke 扇区内才出现 GOE 型排斥。在我们的工作中，情况恰好相反：算术结构产生混沌。这是两个方向上的镜像现象。

图 1．算术哈密顿量一览。(a) 由 Riemann ξ 函数构造的 50×50 Jacobi 矩阵 J50 的对数刻度热图：对角元 αn（在位能）与非对角元 bn（跃迁振幅）完全由 ξ(s) 的 230 位高精度矩量确定，自由参数为零。(b) J50 的前 25 个本征值（换算为零点坐标 γn=1/√λn）以约 10-15 的相对误差锁定 Riemann 零点。

这不是拟合。我们的构造没有任何可调参数。每一个矩阵元都由 L 函数通过一条确定性的数学流水线唯一决定。量子混沌行为是从算术结构中涌现出来的，而非被人为工程化进去的。

二、构造方法：从 L 函数到量子哈密顿量

构造过程分为四步，每一步都是确定性的、可复现的。

2.1 第一步：完备化 L 函数

我们使用三个满足函数方程 Λ(s) = Λ(c-s) 的完备化函数：

$$\begin{aligned} \zeta:\quad &\xi(s)=\tfrac12 s(s-1)\pi^{-s/2}\Gamma(s/2)\,\zeta(s), && c=1,\\[2pt] \beta:\quad &\Lambda_\beta(s)=\Big(\tfrac{\pi}{4}\Big)^{-(s+1)/2}\Gamma\!\Big(\tfrac{s+1}{2}\Big)\,4^{-s}\Big[\zeta(s,\tfrac14)-\zeta(s,\tfrac34)\Big], && c=1,\\[2pt] \Delta:\quad &\Lambda_\Delta(s)=(2\pi)^{-s}\Gamma(s)\,L(\Delta,s), && c=12,\\ &L(\Delta,s)=\prod_p\Big(1-\tau(p)p^{-s}+p^{11-2s}\Big)^{-1}. \end{aligned}$$

这里 ζ(s,a) 是 Hurwitz zeta 函数，τ 是拉马努金 tau 函数。Dirichlet β 函数编码高斯整数，Δ 是权 12 模形式。使用三个独立的算术对象可以检验普适性。

为什么选择这些对象？它们都是数论中最基本的 L 函数，具有丰富的算术结构。如果量子混沌行为在这些不同的对象上都能重现，就说明这不是偶然现象。

2.2 第二步：矩量采样

每个完备化 Λ 都是整函数，并在对称轴上取实值。我们在以对称点 s0=c/2 为圆心、半径 R 的圆周上采样：

$$s_k = s_0 + R\,e^{i\theta_k},\qquad \theta_k=\frac{2\pi k}{M},\qquad k=0,\dots,M-1,$$

使用高精度算术（mpmath，230-650 位有效数字）。均值 σ0 用于归一化测度。log(Λ/Λ(s0)) 在圆周上的泰勒系数 dn 由离散傅里叶求和得到，底层 Hankel 矩量测度的矩量 Pm 则由对数导数递推给出。

关键洞察：矩量序列 {Pn} 编码了 L 函数的全部信息。通过 Gram-Schmidt 正交化，我们可以从中提取出一维链的 Jacobi 递推系数。

2.3 第三步：从矩量到 Jacobi 系数

矩量泛函的内积定义为正交多项式由 Gram-Schmidt 方法构造：

$$\begin{gathered} \alpha_{k-1}=\frac{\langle xp_{k-1},p_{k-1}\rangle}{\langle p_{k-1},p_{k-1}\rangle},\qquad b_{k-1}^2=\frac{\langle p_k,p_k\rangle}{\langle p_{k-1},p_{k-1}\rangle},\\ p_k(x)=(x-\alpha_{k-1})p_{k-1}(x)-b_{k-2}^2\,p_{k-2}(x). \end{gathered}$$

这给出 Jacobi 矩阵 JN = tridiag(αn, bn)——一个三对角矩阵。

为什么这是量子哈密顿量？Gram-Schmidt 正交化是 Stieltjes 矩量问题的标准解法。它给出的 Jacobi 矩阵自动是厄米的（对称的），因此是一个合法的量子哈密顿量。对角元 αn 是在位能，非对角元 bn 是跃迁振幅。这个构造是唯一的——给定矩量序列，Jacobi 矩阵就被唯一确定。

2.5 锁定子空间协议

截断的 N×N Jacobi 矩阵只复现最低的若干零点。当一个算出的本征值 γ = 1/√λ（其中 λ 是 J 的降序本征值）与由独立方法算出的零点在相对误差 < 10-4 内一致时，我们才将其锁定。零点仅进入这一事后核验——从不进入构造。

谱统计使用锁定能级；求积伪影被排除。动力学名正言顺地使用完整截断矩阵，因为有限 N 格点晶格正是量子模拟器所实现的物理对象。

2.6 退展（unfolding）

为了与随机矩阵理论的预言比较，我们需要将本征值"退展"为无量纲形式。对于第 n 个本征值 λn，退展后的间距为 sn = (λn - λn-1) / 平均间距。

三、实验 1：Wigner 能级排斥

这是量子混沌最基本的指纹。

在可积系统中，能级互不关联，间距分布是泊松分布 P(s) = e-s——能级可以任意接近。在量子混沌系统中，能级相互排斥，间距分布遵循 Wigner-Dyson 分布——在 s=0 处线性趋于零，意味着能级倾向于保持距离。

我们发现了什么？

每一个算术哈密顿量——ζ、β、Δ、以及它们的乘积——都展现出强烈的能级排斥。相邻能隙比 ⟨r⟩ 显著高于 GUE 预言值 0.600：

为什么 ⟨r⟩ 超过 GUE 预言？因为 Jacobi 矩阵具有超出随机矩阵的额外结构——算术关联对谱施加了更强的刚性。这不是缺陷，而是特征：它区分了算术量子混沌与随机矩阵混沌。

这意味着什么？能级排斥是量子混沌的标志。我们的算术系统展现出与重核、量子台球相同的统计行为——尽管它的起源完全不同。

四、实验 2：波包动力学与形状因子斜坡

谱统计告诉我们关于本征值的信息。但量子系统不仅仅是谱——它还关乎动力学。一个局域化的态如何在时间中演化？

三种典型行为：

  • 晶体（均匀链）：波包弹道式传播，形成清晰的光锥。最终复活——回到初始态——因为谱是周期的。
  • 安德森绝缘体（随机无序）：波包永远不移动。它局域在初始位置——安德森局域化。
  • 算术链：展现出第三种行为——伪安德森区域。波包扩散到有限区域（RMS ≈ 10）后停止，既不弹道传播，也不完全局域。

图 2．三链对比。左：ζ-Jacobi（伪安德森，RMS ≈ 10）。中：均匀晶体（弹道光锥，RMS ≈ 35）。右：洗牌安德森（局域，RMS ≈ 0.4）。

关键发现：没有复活。在均匀链中，波包在时间演化后完美复活（Prev = 0.993）。在算术链中，波包不可逆地弥散——信息被扰乱到所有基态中，永不返回。这是量子混沌的动力学标志。

五、实验 3：证据链

两个独立的诊断——谱统计和波包动力学——都指向量子混沌。但这会不会是某种构造假象？为了排除有限尺寸效应和构造偏差，我们运行了三个额外的诊断测试：

5.1 洗牌相变：算术次序才是原因

如果量子混沌特征来自 Jacobi 系数的特定排列（即来自算术结构），那么随机洗牌这些系数应该会摧毁它。

我们做了什么？从有序（0%）到完全洗牌（100%）连续插值，观察 ⟨r⟩ 从 ~0.71 坍缩到 ~0.39——恰好是泊松值。

结论：量子混沌特征是脆弱的——它需要精确的算术排列。打乱次序，混沌就消失了。这证明混沌来源于算术结构本身，而不是系数的数值分布。

5.2 逆参与比（IPR）：本征态是扩展的

IPR 衡量本征态的局域化程度。局域态（安德森/可积）具有高 IPR ~ 1；扩展态（量子混沌）具有低 IPR ~ 1/N。

算术 Jacobi 矩阵的 IPR 与完全扩展的本征态一致——证实了遍历性。

5.3 对硬件噪声的鲁棒性

我们在 Jacobi 矩阵上添加随机扰动。量子混沌特征在显著噪声下（高达 ~30% 扰动）仍然存活，证实了结构稳定性。

5.4 有限尺寸标度

我们检验了从 N=22 到 N=100 的尺寸范围内的行为。量子混沌特征在所有尺寸上都存在，并且随着尺寸增大而增强——排除了有限尺寸假象。

5.5 算术判别对照：艾森斯坦级数 E4

为了检验量子混沌是否来自算术结构的特定类型，我们用艾森斯坦级数 E4（一个不具有相同零点结构的模形式）构造了 Jacobi 矩阵。

结果：E4 的 Jacobi 矩阵展现出泊松统计——可积行为。这证明量子混沌不是所有算术对象的普遍特征，而是特定于具有非平凡零点的 L 函数。

5.6 动力学不可积性：非时序关联子（OTOC）

OTOC 衡量初始相近的量子态发散的速度——量子混沌的动力学标志。

在算术系统中，OTOC 以类李雅普诺夫指数衰减，表明信息扰乱——这是没有经典对应的纯量子效应。

六、实验 4：干涉指纹

这是本工作中最令人惊奇的发现。

我们定义了一个双参数函数 F(s,t) = 量子重叠——点 s 处的态在时间 t 后与初始态有多"相似"。

惊人的结果：在 L 函数的非平凡零点处，F(s,t) 展现出完全相消干涉（F ≈ -1）。L 函数的零点表现为量子干涉图样中的暗条纹。

图 3．四个 L 函数的干涉指纹 F(s,t)，展现出独特图样，并在零点处 F ≈ -1。

为什么这很重要？

在传统的量子混沌中，谱告诉你关于系统的信息，但不携带原始数据的"地址"。干涉指纹不同：它直接将算术信息编码为物理可观测量。两个不同的 L 函数（ζ(s) vs. L(s,χ₄)）产生肉眼可见不同的指纹——你可以看到差异。

这开启了一个新范式：数论变得实验可及。不再需要证明关于零点的定理，我们可以在量子系统中测量它们。指纹是抽象算术与物理观测之间的桥梁。

四个根本区别：

区别 1

混沌的起源

传统量子混沌系统（台球、核）的混沌来自经典动力学的量子化。我们的系统没有经典混沌极限——混沌纯粹来自算术起源。

区别 2

构造性，而非仅观测性

在核物理中，你观测到 Wigner 统计并推断混沌。在我们的系统中，你构造哈密顿量，混沌随之而来。构造是显式的、可复现的、无参数的。

区别 3

直接编码零点

干涉指纹 F(s,t) 直接将 L 函数的零点编码为物理可观测量。没有其他量子混沌系统具有这一性质——在台球中，能级与零点的对应仅是猜想（Berry-Keating）。在我们的系统中，这种联系是构造性的。

区别 4

伪安德森普适性类

波包动力学揭示了一个新的普适性类：伪安德森局域化。系统既不是晶体（弹道），也不是安德森绝缘体（局域）——它占据了一个波包扩散到有限区域后停止的独特区域。这在标准量子混沌分类中不存在。

八、应用方向与未来展望

我们的工作开辟了多个应用方向：

方向 1

RH 的谱方法攻击

如果 Jacobi 哈密顿量的谱编码了 zeta 零点，那么证明谱性质（如谱的简单性、间距分布）可能为 RH 提供新的攻击路径。希尔伯特-波利亚纲领获得了一个具体的候选算子。

方向 2

量子算术模拟

Jacobi 哈密顿量可以在量子计算机上模拟。这开启了实验测量算术量的可能性——零点、L 函数值、素数关联——使用量子线路。数论变成量子实验。

方向 3

量子密码学

干涉指纹对每个 L 函数是唯一的，并依赖于素数分布。这可以作为基于算术的量子签名的基础——安全性基于因式分解或离散对数的困难性，编码在量子干涉图样中。

方向 4

新普适性类

伪安德森区域暗示了一个由算术结构而非无序支配的量子动力学新类。理解这一类可以为凝聚态物理（准晶体、非周期系统）和量子信息（结构化系统中的扰乱）提供信息。

九、三层主张结构

9.1 第一层：数学定理

以下结果在姊妹篇论文中严格证明：

定理 1（Hankel 正定性）：对所有 n ≥ 1，Hankel 行列式 Dn > 0。

定理 2（本质自伴性）：由 Gram-Schmidt 构造的无穷维 Jacobi 算子是本质自伴的。

定理 3（谱表示）：Jacobi 算子的谱恰好是 L 函数的非平凡零点。

严格且已证明。

9.2 第二层：物理猜想

猜想（算术起源的量子混沌）：与 L 函数相关联的算术结构——通过其矩量测度的 Jacobi 递推系数来表达——能够在一维紧束缚哈密顿量中充当量子混沌（Wigner-Dyson）谱统计与动力学统计的一个起源，而无需经典混沌动力学，也无需哈密顿量参数中的随机无序。

由大量数值证据支持。

9.3 第三层：开放问题

与希尔伯特-波利亚猜想的联系。Jacobi 谱是否约束零点位置？算术量子混沌的半经典极限。推测性的，等待证明。

十、量子模拟器实验方案

我们的构造不仅是理论——它可以直接在量子模拟器上实现。我们提供了一个"交钥匙"实验预测包，包含：

  • 待编程的哈密顿量：完整的 Jacobi 矩阵元（αn, bn），精度 230 位有效数字。
  • 可观测预言：能谱、波包动力学、OTOC、干涉指纹的定量预言。
  • 对照实验：洗牌对照、安德森对照、均匀链对照。
  • 硬件噪声预算：对不同噪声水平的鲁棒性估计。
  • 通过/失败判定：明确的定量标准来判断实验是否支持猜想。

任何拥有量子模拟器（离子阱、超导量子比特、冷原子）的实验组都可以直接运行这些实验。

十一、局限与开放问题

我们诚实地报告本工作的局限：

  • 有限尺寸：当前结果基于 N ≤ 100 的截断。更大的系统需要更高精度的算术。
  • Δ 函数尺寸较小：由于 Hankel 条件数的限制，Ramanujan Δ 只能达到 N=22。
  • GUE vs GOE：区分这两个系综需要更大的 N，留作开放问题。
  • 半经典极限：算术量子混沌的半经典对应尚不清楚。

这些局限不是缺陷——它们是未来研究的方向。
